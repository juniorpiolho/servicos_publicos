# Requisitos Funcionais e Não-Funcionais do Sistema

## 1. Requisitos Funcionais (RF)
| ID | Descrição |
| :--- | :--- |
| **RF01** | O sistema deve listar todos os serviços públicos disponíveis. |
| **RF02** | O usuário deve ser capaz de buscar serviços por nome ou palavra-chave. |
| **RF03** | O sistema deve permitir a filtragem de serviços por categoria. |

## 2. Requisitos Não-Funcionais (RNF)
| Categoria | Descrição |
| :--- | :--- |
| **Usabilidade** | A interface deve ser intuitiva e simples. |
| **Desempenho** | O tempo de carregamento da lista inicial de serviços não deve exceder 2 segundos. |
| **Compatibilidade** | O aplicativo deve funcionar perfeitamente em dispositivos Android e iOS. |
